# Codex API 标价估算器设计

## 显示与开关

在「设置 → ChatGPT Codex」添加「API 标价估算」开关。默认关闭，选择随桌面配置保留。开启后，DSH 会话界面显示一个沿用主题颜色的轻量悬浮窗。拖住标题区即可移动，折叠后仍可拖动并查看当前会话金额。保留最近位置，窗口尺寸变化时将悬浮窗约束在可见范围内，并提供「重置悬浮窗位置」操作。悬浮窗之外的区域继续接受 DSH 原有交互。关闭开关立即隐藏悬浮窗并停止估算刷新。

卡片用美元显示两项金额。

- **当前会话**只累计选中会话自己经本插件发出的请求。切换会话时随之切换。
- **全部累计**累计当前 DSH 桌面配置保留的所有会话中经本插件发出的请求，包含开启功能前留有用量记录的历史会话。分叉继承的请求只归原会话。删除会话后，累计会随保留记录重新计算。

展开详情可看已计价的请求数、无法计价的请求数以及费率表日期。用量齐全且无请求时显示空状态。部分请求无法计价时显示「已计价小计」，所有请求均无法计价时显示「暂无可估算金额」。

## 计价口径

按请求使用 OpenAI 公布的 Standard API 模型 token 标价。分别计算未缓存输入、缓存读取、缓存写入和输出。用每次请求的输入总量判断该模型是否落入长上下文费率。输出 token 已含推理用量时直接使用输出计数。金额汇总后才舍入，极小的正金额会以低于显示精度表示。

费率表记录精确模型 ID、来源、核对日期、适用的上下文档位和已知有效期。匹配不到公开 API 价格、无法核对缓存写入费率，或缺少足够用量时，标记该请求未计价。估算口径为模型 token 标价，DSH 本地工具执行和 OpenAI 托管工具的独立按次费用不并入估算。

[OpenAI API 标价](https://developers.openai.com/api/docs/pricing) · [GPT‑6.2 Sol 模型费率与长上下文说明](https://developers.openai.com/api/docs/models/gpt-6.2-sol)

## 费率自动同步

模型目录和 API 费率表独立更新。Codex 目录决定模型何时出现在选择器里。估算器从 OpenAI 公开定价页和模型文档获取 Standard 费率，按精确模型 ID 匹配。同步只读取公开资料，无需账户凭据。新模型可以先出现在选择器里，并显示「暂无可用标价」。官方费率通过校验后，会在当前 DSH 运行期间用于估算，无需重新打包或重启。

开启估算器时检查费率缓存，运行期间定期刷新。发现费率表未覆盖的模型时安排一次去重同步。将通过校验的费率存入本地缓存，保留来源、最近成功同步时间和适用范围。同步成功后，按新费率的适用范围重算受影响的请求，并刷新两项累计。

校验包括精确模型 ID、Standard 档位、每百万 token 的计价单位及所用的上下文和缓存规则。网络失败、文档格式变化或同一档位的来源相互冲突时，继续使用仍适用的上次校验结果。缺少可用费率的请求保留未计价状态，金额栏显示已计价小计或「暂无可估算金额」。

## 实现路线

复用 DSH 的会话日志。读取每个请求保存的 `message.source.provider`，只在值精确等于 `codex-responses` 时计入，再用 `message.source.model` 查价。OpenAI API 即使使用同一个模型 ID，也会保留自己的 provider。`assistant/message` 报告用量时优先使用它，按原生 attempt 边界处理可归属的重试记录。供应商无法确认时将记录留在估算范围之外。用 DSH 的继承前缀边界排除复制内容。这个方案可以回算现有会话，并跟随 DSH 的保留与删除行为。

插件自行记录每次请求也是可行方案，能覆盖更多后台调用，但需要增加持久账本，而且老会话无法仅靠账本回算。直接使用 DSH 的会话 token 合计更简洁，但它混合模型及请求，无法正确处理每次请求的长上下文费率。这次采用会话日志方案。

在授权的本地 Host 上读取会话记录，只向悬浮窗返回金额、用量计数及可用状态。日志内容和凭据不进入估算界面。启用时分批折算历史，缓存已处理结果，随后增量刷新。使用 DSH 原生挂载点展示悬浮卡片，关闭时取消无用刷新。首版继续使用当前验证过的 DSH `0.2.2-rc.3`。

## 验收

- 先写测试覆盖四类 token、长上下文边界、会话中途换模型、无公开标价、重试与分叉去重，以及关闭开关后的生命周期。
- 用模拟官方资料验证新模型先可选、费率后补的流程。覆盖费率首次出现后自动入表、历史请求重算、同步失败保留有效缓存，以及过期或不明确费率保持未计价。
- 用模拟会话覆盖同一模型 ID 通过插件订阅与 OpenAI API 混用、来源缺失、部分缺失的用量、不可读的历史记录及切换会话时的过期结果。分别验证当前会话与全部累计。
- 在当前 DSH 桌面端打开悬浮窗，使用已有测试会话核对两笔金额，检查浅色、深色、拖动、缩放后的边界、折叠及关停。验收可以复用已保存的用量。
