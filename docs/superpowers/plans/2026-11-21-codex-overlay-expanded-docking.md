# 展开悬浮窗左右吸附实施计划

**目标**　展开面板和折叠胶囊使用同一套左右吸附规则。展开面板贴边后保留详情，点击标题栏可沿同一侧切换为竖向胶囊或重新展开。

**范围**　沿用 `FloatingWindow` 的边缘位置、标题栏、偏好保存和过渡动画。松手进入吸附区时贴边，拖出吸附区后恢复自由摆放。窄窗口继续按可移动距离缩小吸附区，并保留中间的自由摆放位置。

- [x] 在 `test/client-contract.test.mjs` 的拖拽测试中覆盖展开面板首次左右吸附、脱离、换边及窄窗口，先确认旧代码无法保存新的边缘位置。
- [x] 在 `src/client.cjs` 的 `FloatingWindow` 中统一拖拽预览和松手时的横向边界，两种形态共用边缘判定。自由摆放继续使用原有边距。
- [x] 运行客户端契约测试、全量回归和语法检查。在 Chromium 渲染验证左右吸附中间帧、详情保持可见、贴边折叠与展开、脱离、窄窗口和减少动态效果。
