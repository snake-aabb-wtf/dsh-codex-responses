# 悬浮窗四边吸附实施计划

**目标**　横向胶囊和展开面板都可吸附到 DSH 内容区的顶边或底边。顶部向下展开，底部向上展开，切换全程保持对应的边缘固定。

- [x] 先用客户端和设置测试覆盖上下边缘的保存、重新读取、角落判定、短窗口和方向键移动。继续验证旧位置和左右吸附。
- [x] 在 `src/client.cjs`、`src/typert.mjs` 和 `src/floating-preferences.mjs` 接受 `top`、`bottom`。拖拽松手时选择范围内最近的边。角落等距时优先保留当前边缘，其余按固定顺序选择。
- [x] 从 DSH 标题栏样式读取顶部安全范围。沿用 160 毫秒的吸附过渡，以 `bottom` 和高度动画保持底部锚定。系统减少动态效果时直接定位。
- [x] 在 Chromium 渲染中验证两种形态的上下吸附中间帧、折叠和展开的边缘、切换中途反向、横向位置保存、窗口缩放与重载，并运行全量回归。
