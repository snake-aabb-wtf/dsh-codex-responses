# Codex API 标价估算器实施计划

**目标**　在当前 DSH 设置启用可拖动的估算窗，展示本插件当前会话与保留会话合计的 API 标价估算。

**设计**　[已确认设计](../specs/2026-11-19-codex-api-cost-estimator-design.md)。计价数据来自官方公开定价，使用记录来自 DSH 原生会话日志。保留当前工作区内已经实测的设置页改动。

- [x] 在 `test/cost-pricing.test.mjs` 先写同步、费率解析、冲突、缓存、失效和新模型补价测试，再实现 `src/cost-pricing.mjs`。
- [x] 在 `test/cost-usage.test.mjs` 先写渠道隔离、按请求计价、重试和分叉测试，再实现 `src/cost-usage.mjs`。
- [x] 写聚合和前端契约测试，接入本地专属 Remote、持久开关、增量读取和可拖动悬浮窗。关闭时停止刷新。设置页提供重置位置。
- [x] 对整条链路做复核，运行 DSH 桌面内置运行时的全量测试和打包。将插件装进当前桌面客户端，用已保存的会话验证金额、切换、拖动、折叠与开关，恢复实测前的偏好。

复核补充了两个数据边界。历史费率按适用区间查询。同一屏的两笔合计使用同一个费率版本。归档会话按持久化修订号判断是否需要重读。公开费率同步只使用本地已有的模型标识。

`0.2.1` 通过 87 项测试。当前 DSH `0.2.2-rc.3` 用保存的两笔 Codex 请求折算为 $0.0384。验证了官方费率同步、缓存复用、离开会话后的全局累计、主题、拖动、折叠、还原窗口时的位置约束，以及复位和关闭。

## 独立悬浮窗与内容选项

悬浮窗总开关、位置和内容勾选保存在同一份桌面偏好中。新版读取旧偏好时沿用是否开启及已存位置，首个「API 标价估算」内容默认选中。总开关关闭时可调整内容。只有窗口开启且至少一个内容被选中时才显示，估算器仅在自身被显示时扫描记录和同步费率。
