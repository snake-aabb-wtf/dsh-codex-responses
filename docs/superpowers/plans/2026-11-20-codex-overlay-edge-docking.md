# 悬浮窗左右吸附实施计划

**目标**　折叠胶囊在松手时可平滑贴合 DSH 窗口的左边缘或右边缘。

**方案**　拖动期间显示实际拖拽位置。松手时根据胶囊外框与边缘的距离判定吸附，从当前画面用 160 毫秒的减速过渡滑到边缘。位置值在原有 `x/y` 上增加可选的 `edge`，保存后按边缘和纵坐标布局，窗口缩放和展开时继续贴边。减少动态效果时直接贴边。

**判定**　通常距离边缘 24 CSS 像素以内会吸附。窗口很窄时，左右各使用可移动距离的三分之一作为范围，上限仍为 24 像素。已吸附的悬浮窗可沿边移动，拖出范围后松手恢复自由摆放。旧版只保存坐标的位置按原坐标恢复。

**贴边形态**　自由摆放的摘要横排，贴边的摘要竖排，文字保持正向可读。吸附与脱离时插值宽高和位置，并切换摘要布局。竖胶囊的整块区域可点击，详情从所贴边缘向窗口内侧展开，折叠后恢复竖排。
