# 悬浮窗折叠动效实施计划

**目标**　把同一个悬浮窗的摘要和明细连接成约 220 毫秒的展开、180 毫秒的折叠过渡。

**方案**　使用实测的高度和 Web Animations API 为外框插值。摘要和明细共用一列宽度和同一份数据，以正常字号交叉淡入淡出。宽度取摘要所需宽度与原有的 258 像素卡片宽度中较大的值，并受视口限制。标题栏按钮持续挂载，拖动后的窗口沿保存的位置展开并始终受窗口边界约束。

**范围**　从 `src/client.cjs` 的现有悬浮窗入口触发，覆盖键盘、拖拽、快速反向和系统减少动态效果设置。

- [x] 在真实 Chromium 中复现外框没有中间尺寸的情况。测量默认右边缘、折叠与展开的中间帧以及反向点击时的起点。
- [x] 将显示逻辑和数据订阅分开。两个视图使用每个勾选项的同一份状态，隐藏视图退出焦点和无障碍树。用现有客户端测试覆盖内容和订阅生命周期。
- [x] 实现尺寸、位置、圆角及内层淡入淡出。调整拖拽时停止进行中的几何动画，保留点击与拖拽的区分。测试靠近屏幕边缘时的边界与系统减少动态效果。
- [x] 运行客户端回归测试、桌面运行时的完整测试和语法检查。用浏览器验证选中所有内容和仅选中一项两种布局，覆盖窄窗口、反向、拖拽和键盘操作。在当前 DSH 桌面检查展开和折叠的中间帧，以及折叠过程中标题栏手柄的位置。
- [x] 在 Chromium 测量展开、折叠和中途反向的宽度与横坐标。用单项摘要核对最小宽度，用三项摘要核对按内容撑宽，用窄窗口核对两态边距和摘要折行。
